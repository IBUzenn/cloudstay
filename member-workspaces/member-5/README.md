# Member 5 Workspace: QA & Documentation

Welcome, Member 5! This is your self-contained workspace for the CloudStay Student Hostel Booking System project.

## Your Role

You are responsible for Quality Assurance (QA) and Project Documentation. Your primary goals are to:
1. Develop and execute the project's testing strategy (Unit, Integration, and Manual Acceptance Testing).
2. Author the final project documentation, including the User Manual and Final Technical Report.
3. Ensure the project meets all functional requirements and is ready for submission as a cohesive group project.

## Getting Started

1. Read this `README.md` to understand your role.
2. Follow the instructions in `SETUP.md` to configure your testing and documentation environment.
3. Review `TASKS.md` for a detailed breakdown of your assignments.
4. Familiarize yourself with `INTERFACES.md` to understand how the system components interact for testing purposes.
5. Use `CHECKLIST.md` to track your progress.
6. Record your completed work in `CONTRIBUTION.md` and store any testing evidence (screenshots, test reports) in the `evidence/` folder.

## Key Focus Areas

- **Testing Strategy:** Implement Jest tests for both frontend components and backend API endpoints.
- **Acceptance Testing:** Define manual test scripts and verify end-to-end functionality.
- **Technical Writing:** Synthesize the group's work into a professional technical report, ensuring it reflects collective authorship ("our team", "we implemented").
- **User Manual:** Create clear, visual documentation guiding end-users on how to use the CloudStay system.

If you need any clarification on your tasks or require assistance with the testing framework, please coordinate with the relevant team members (e.g., Member 1 for frontend testing, Member 2 for backend API testing).
